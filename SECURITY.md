# Política de Seguridad

## Reporte de vulnerabilidades
Si has identificado información sensible o datos personales en este repositorio que no deberían ser públicos, por favor contacta con nosotros de forma responsable para que podamos actuar.

## Contacto
- **Correo electrónico:** En mi README PERSONAL.
- **Método alternativo:** Abre un issue en el repositorio con la etiqueta `[SECURITY]` (para asuntos no sensibles).

## Expectativas
- Responderemos en un plazo de 48 horas.
- Tomaremos medidas para corregir cualquier vulnerabilidad o eliminación de datos sensibles.
- Mantendremos la confidencialidad de los reportes.

## Nota sobre el contenido
Este repositorio contiene información obtenida de fuentes abiertas. Si crees que algún contenido viola derechos de autor, leyes de privacidad u otras normativas, indícalo y lo revisaremos.
